# Getting help

Start with the [README](README.md), [deployment runbook](docs/DEPLOY.md), and [operations guide](docs/OPERATIONS.md). Search existing issues before opening a new one.

For a bug, provide the commit, Node/npm versions, deployment mode, expected and observed behavior, and a minimal local reproduction. Include sanitized logs, not credentials, JWTs, message bodies, or real mailbox addresses. For configuration questions, open a question using the issue chooser.

Use [private vulnerability reporting](SECURITY.md) for security issues. This is a community-maintained portfolio project with no paid support or availability guarantee.
