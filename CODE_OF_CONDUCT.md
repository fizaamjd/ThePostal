# Code of conduct

We welcome contributors of all backgrounds and experience levels. Be respectful, explain disagreements with evidence, and keep feedback focused on the work. Respect privacy and give credit for others' contributions.

Harassment, discrimination, threats, sexualized attention, publishing private information, and repeated disruptive behavior are unacceptable in repository issues, pull requests, and other project spaces.

The maintainer may edit or remove harmful content, close discussions, or restrict participation. Responses should reflect severity and context: clarification or a warning where appropriate, temporary restrictions for repeated misconduct, and removal for serious abuse.

To report misconduct privately, contact [Fiza Amjad through her GitHub profile](https://github.com/fizaamjad897) using an available contact method; do not post private reports in public issues. If no private contact is available, use GitHub's **Report abuse** control on the offending content. This policy does not promise a confidential reporting channel within GitHub issues.
