What a mail server must get right

The reply code decides everything

transient · 4xx
451 4.7.1 Greylisted, try again later

The server may simply be busy. Bouncing here would discard mail that is perfectly deliverable.

retry schedule · exponential, full jitter
15s30s1m2m4m
Deferred · attempt 2 of 5
permanent · 5xx
550 5.1.1 Recipient address rejected

That is the domain's final answer. Retrying it would burn every attempt on a guaranteed failure.

retry schedule · none
now
Failed · bounced immediately

Jitter matters more than it looks. Without it, every message deferred in the same window retries at the same instant, and the recovering server is hit by the whole backlog at once.
