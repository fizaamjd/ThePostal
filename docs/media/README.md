# Demo media

`postal-demo.mp4` is a deterministic capture of the original `postal-reel.html` portfolio presentation: 80.6 seconds, 1200 × 1200, 30 frames per second, H.264, no audio. The entire timeline is included. The original HTML is preserved unchanged; Google Fonts requires network access when opening it directly.

The presentation illustrates the UI, SMTP phases, retry behavior, and architecture. Its animated numbers and scenarios are presentation content, not a live deployment, measured benchmark, or service guarantee. Use the integration tests to verify implementation behavior.

[Capture metadata and SHA-256 checksums](demo-metadata.json) identify the source and video. The repository MIT license covers original project materials; third-party font licenses remain with their respective owners.
